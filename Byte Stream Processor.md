|--------------|---------------|

| **Corrupt data** | Add CRC checks |
| **High memory** | Bound queues |
| **Slow sink** | Apply backpressure |
| **Dropped packets** | Increase socket buffer |
| **CPU spikes** | Profile hot paths |
